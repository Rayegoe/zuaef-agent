Then read the relevant `work_packets/`, `contracts/`, and `schemas/` for the current task.

`ZUAEF_QUANT_SPEC_V3.md` is the consolidated reading copy. If a wrapper file conflicts with a numbered normative file, the numbered file wins. If any spec conflicts with newer runtime evidence, runtime evidence wins and the discrepancy must be documented before code changes.
