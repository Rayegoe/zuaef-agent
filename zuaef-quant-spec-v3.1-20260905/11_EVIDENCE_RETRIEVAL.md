# 11 — Evidence Retrieval v1

Purpose: targeted Agent context, not broker-terminal replication.

Priority:
1. market breadth;
2. sector breadth;
3. announcements;
4. corporate actions;
5. verify existing position/cost-basis coverage before adding another source;
6. minute price/volume only where current timing or experiments require it.

Announcements start as risk/event filters, not automatic alpha.

Historical evidence must disclose:
source, event_time, available_at, PIT status, revision status.
Unknown historical availability => NON_PIT and excluded from strict replay promotion evidence.
