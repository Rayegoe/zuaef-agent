# ZUAEF Method Kernel — Lightweight Spec Pack

核心思想：

> Skill 将死，不代表知识不重要；真正长期有价值的是方法、证据和可验证反馈。

这个包只做四件事：

```text
1. Core 加一个很薄的方法论内核
2. 泛化现有 independent reviewer
3. Learning promotion 从 Skill-centric 改成 intervention-neutral
4. 增加最小 Ablation Harness
```

不做：

```text
新 Agent
新 Workflow
新数据库
新 Skill 平台
强制八步法
```

入口：

```text
00_START_HERE.md
05_CHANGE_PLAN.md
07_CODEX_MASTER_PROMPT.md
```
