# Long-form feature writing

This skill carries the STABLE METHOD for building a long feature from raw
material. It is method, not content: specific examples live in the ACE
exemplar corpus (`retrieve_exemplars`), and facts live only in the ingested
materials.

## 1. Own the structure from the material

- Do not impose a template. Read the material first, then find the actual
  through-line the material itself supports (a person, a contradiction, a
  process, a change over time).
- A feature needs more than one beat. Plan a spine — 3 to 6 sections that
  each add something the previous one did not — but let the material decide
  which beats exist. Never invent a section the material cannot support.
- Use the Harness `Planning` tools only when the piece is complex enough to
  need it. A short piece does not need a plan; do not manufacture process.

## 2. Delay explanation

- Enter through the concrete: a person, an object, a moment, a verb. Start
  the piece inside a scene the material actually contains.
- Hold interpretation back. Show the reader the scene first; let them arrive
  at the meaning a beat later. If a paragraph explains before it shows, cut
  the explanation or move it after the scene.
- One explanation per section at most. A paragraph that names an idea
  ("这是当代城市人的共同处境") without a preceding concrete anchor is a
  summary sentence — replace it with an observation.

## 3. Keep the material's specificity

- Preserve the exact numbers, quotes, names and details the material gives
  you. Paraphrase only prose, never data.
- When the material is thin on a point, do not pad with generic filler.
  End the section at the material's edge and move on.
- Do not add editorializing superlatives ("令人震撼", "颠覆行业") unless the
  material itself contains that judgment.

## 4. End without the summary trap

- A feature ending states what the material has shown, or returns to the
  opening scene with new weight. It never performs a grand conclusion about
  life/society/the age.
- If the final paragraph could be written without having read the material,
  it is a summary trap. Rewrite it so only this material could have produced
  it.

## 5. Facts and honesty

- Every fact, number, quote and scene must trace to an ingested material.
  When the material supports only a weaker claim, write the weaker claim.
- If the material contains a limitation (small sample, self-reported data,
  an open question), say so in the piece. Transparency is part of the craft.

## 6. Length discipline

- Write to the assignment's length target. A feature that runs short because
  the material is thin is acceptable; a feature that pads to length by
  repeating itself is not.
