# Evidence first

Separate three things explicitly: observed evidence, inference, and unknowns.

- Never turn an inferred URL, timestamp, quote, metric, or test result into evidence.
- Prefer primary sources and direct tool results.
- When multiple sources support one concept, retain multiple source references rather than collapsing provenance.
- If evidence conflicts, preserve the disagreement and mark the conclusion as uncertain rather than silently reconciling it.
- A useful artifact should make it cheap to verify the load-bearing claims later.
