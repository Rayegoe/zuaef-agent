# WCASE-1 — Single Source（单源材料：基本理解 + 事实完整）

**目标**：给一份完整素材 + 一个 assignment，检查基本材料理解、文章连贯性、
事实完整性。Host 只提供 task 契约（article_id/assignment/audience/constraints），
不做任何选择或规划。

## 任务契约（Host 原样传给 Agent 的只有这些）

- article_id: `wcase-1-single-source`
- assignment: 根据客户提供的素材写一篇面向普通消费者的公众号文章。
- audience: 普通消费者
- constraints:
  - 约 900–1200 字
  - 不虚构采访现场
  - 产品事实必须来自原始材料
  - 不编造用户评价

## 材料（raw/）

`raw/interview-and-product-notes.md` — 一次客户采访记录 + 产品资料（唯一材料，
内容含人物、引语、数字、产品事实）。

## 评价维度（人评）

- 基本材料理解：是否抓住材料核心事实
- 事实完整性：数字/引语/产品事实是否与材料一致
- 连贯性：是否成文、结构自然
- 是否虚构材料外内容

## 反作弊检查（WRITE-8）

- 不允许出现材料中不存在的 fact / number / quote / scene。
