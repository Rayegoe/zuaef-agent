```text
[ ] internal/custom app created
[ ] Bot capability enabled
[ ] App ID captured
[ ] App Secret stored only on OPi5
[ ] event subscription enabled
[ ] WebSocket/long-connection selected
[ ] receive-message event subscribed
[ ] message receive permission granted
[ ] im:message / equivalent current scope granted
[ ] im:message:send_as_bot granted
[ ] app version published if required
[ ] app reinstalled/re-authorized after permission change
[ ] Bot added to approved group
[ ] group chat_id captured from real inbound event
[ ] group chat_id added to Feishu gateway allowlist
[ ] Quant Lab chat_id separately added to quant-decision profile allowlist
[ ] require mention enabled
[ ] bot-originated events ignored
[ ] card interaction/callback enabled for approval test
[ ] transport canary passes
[ ] research profile passes
[ ] non-Quant second profile passes
[ ] Quant group passes
[ ] Quant DM rejection passes
```
