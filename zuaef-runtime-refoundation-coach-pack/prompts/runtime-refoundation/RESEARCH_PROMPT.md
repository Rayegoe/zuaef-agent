# Focused Research Prompt

Use this only when a runtime decision depends on external/upstream behavior.

Research the smallest unresolved question.

Preferred sources:
1. Pydantic AI / Pydantic AI Harness source and docs;
2. provider API docs where relevant;
3. production traces/issues only when needed.

Do not turn research into a survey of Agent frameworks.

Return:
- exact mechanism;
- source;
- implications for ZUAEF;
- whether an upstream primitive already solves the need;
- smallest experiment required before adoption.
