# 写作经验与风格总结

本文档从《给马上鞍，给业务建跑道》三版修订中提炼，供 agent 生成同类文章时参考。

---

## 一、文章结构模式

面向老板的 AI 落地文章有一个固定骨架，不是模板但可以作为检验清单：

```
导语（1 句判断，加粗）
  ↓
开头钩子（老板正在经历的困惑）
  ↓
【图1】一、核心判断（AI 不只是会聊了）
  ↓
【图2】二、困境第一层（会动手就必须有边界）
      → 具体化：鞍、缰绳、记录
  ↓
【图3】三、困境第二层（有工具不等于有结果）
      → 接地气：员工学提示词、公众号更快订单没变多
  ↓
【图4】四、具体案例（第一条跑道：竞品诊断）
      → 输入 → 拆解 → 输出 → 行动顺序
  ↓
【图5】五、自测框架（老板真正要问的三个问题）
      → 三个问题的答案就是 CTA 的"理论基础"
  ↓
【图6】CTA 收束（所以我们把三个问题做成了工具）
      → 关注 → 回复 → 领取 → 用 X 分钟判断
```

## 二、风格铁律

### 2.1 开头：从老板的眼睛看世界

❌ 不要：
> 过去两年，大部分人理解 AI 的方式没变过。

✅ 要：
> 很多老板现在看 AI，还是在看模型有多聪明。
> 会不会写文章，会不会做 PPT，会不会画图，会不会回答问题。

**法则**：开头第一句的默认主语是"老板"。如果你在写"人们""大家""大部分人"，停下来，改成"老板"。

### 2.2 导语先于正文

正文第一段之前放一句加粗导语，让读者一屏之内知道文章要说什么：

> AI 落地的关键，不是模型更强，而是企业有没有一条能让 AI 跑起来的路。

一句话，一个判断，不加解释。

### 2.3 品牌/技术名词：三合一

不要展开列品牌。把 OpenAI、Anthropic、Google 合并为一句：

✅
> OpenAI、Anthropic、Google 都在把 AI 从"回答问题"推进到"操作浏览器、使用工具、完成任务"。

❌
> OpenAI 的 Operator 和 ChatGPT agent 已经把 AI 从"回答问题"推进到"使用浏览器完成任务"。Anthropic 的 Claude 可以像人一样看屏幕、点按钮、输入信息。Google 的 Project Mariner 也在做网页操作和多任务执行。

**法则**：品牌名是论据，不是新闻。合并后立刻接判断句（"这意味着一件事：……"）。

### 2.4 隐喻密度：不超过 2 个核心隐喻

一篇文章一个主隐喻（马/鞍/缰绳/跑道）+ 一个辅隐喻（跑道上的站点）。不引入第三个。

❌ 鞍 + 缰绳 + 铆钉 → 隐喻过密，"铆钉"偏文学，老板不秒懂。
✅ 鞍 + 缰绳 + "企业才知道 AI 到底做了什么、凭什么做、结果能不能信" → 商业表达。

**法则**：第三个隐喻出现时，用白话替换它。

### 2.5 用词降级：猛兽 → 风险

面向老板的判断型文章，不用恐吓式词汇。

❌ "它就是猛兽，不是工具"
✅ "它就不是工具，而是风险"

### 2.6 风险表达降级：引用 → 原则

不直接引用具体公司的开发指引，除非附出处链接。

❌ "OpenAI 自己在开发指引里也强调：应该在隔离浏览器或容器中运行……"
✅ "这类 Agent 产品的安全设计里，一个基本原则就是：隔离运行、限制访问范围，高风险动作必须人工确认。"

### 2.7 段落呼吸：纯文字段不超过 3 行

手机端阅读，每段不超过 3 行。超过就拆。

### 2.8 小标题：带序号，稳

❌ 纯文字小标题（"AI 不只是会聊了"）→ 像正文断裂
✅ 带序号（"一、AI 不只是会聊了"）→ 公众号阅读更清晰

5 个小标题 = 5 个认知台阶。标题要直接，不文学。

## 三、常见错误与修正模式

| 错误 | 表现 | 修正 |
|------|------|------|
| 开口太大 | "过去两年，大部分人……" | 改成"很多老板现在看 AI……" |
| 品牌展销 | 列 3 个公司各 1 句话 | 合并为 1 句，立刻接判断 |
| 隐喻过载 | 3+ 个隐喻叠用 | 砍到 2 个，第三个用白话 |
| 用词恐吓 | "猛兽""崩塌""淘汰" | 降为"风险""变化""重新整理" |
| 引用不当 | 直接引官方指引不出处 | 改为原则性表述 |
| CTA 硬贴 | "如果你想……我们准备了……" | 改为"所以我们把 X 做成了……" |
| 收尾重复 | "马已经够强了"+"马已经越来越强了" | 删一处，另一处改成判断变体 |
| 首屏无判断 | 开头 3 段还在铺垫 | 第 1 段就亮判断 |
| 报告一逗到底 | 一长句讲完输出 | 拆成 4 行短判断 |
| 图注不一致 | 正文改"风险"，图注还是"猛兽" | 改图注与正文一致 |

## 四、CTA 的自然长出

转化不是"在结尾加一个广告"。CTA 必须在逻辑上从正文最后一个判断里长出来。

**模式**：

```
文章最后一个判断（三个自测问题）
  ↓
"所以，我们把这三个问题做成了一份小工具"
  ↓
《工具名称》
  ↓
关注 → 回复关键词 → 免费领取
  ↓
用 X 分钟判断：{一句话价值}
```

❌ 断裂式 CTA：
> 如果你想先做一次自查，我们准备了一份……

✅ 长出式 CTA：
> 所以，我们把这三个问题做成了一份小工具：
> 《中小企业 AI 跑道自测表》

**法则**：CTA 的第一句必须包含上文刚讲的那个概念（"三个问题"），让读者觉得"这不是广告，是刚才那三个问题的自然下一步"。

## 五、配图与正文的一致性

### 5.1 图注必须与正文用词一致

正文改了什么词，图注同步改。读者看到图注和正文打架 = 专业感瞬间归零。

### 5.2 图注与小标题可以统一

"【图2：会动手，就必须有边界】" — 图注与小标题用同一句话，降低读者的认知切换成本。

### 5.3 配图不是插图，是视觉论证

每张图承担一个论证任务：开场锚点、困境画面、方法示意、判断总结、结论收束。不是"画一个好看的图"，是"让判断被看见"。

- [ ] 每段不超过 3 行？
- [ ] 小标题带序号（一、二、三）？
- [ ] 报告/输出拆成了短判断（不是一逗到底）？
- [ ] CTA 的第一句包含了上文概念？
