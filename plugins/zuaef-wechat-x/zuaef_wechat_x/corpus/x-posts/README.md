## 目录结构

```
x-posts/
├── README.md       ← 本文件：发布记录索引
├── drafts/         ← 草稿（待审核/待修改）
└── published/      ← 已发布内容
```

## 文件命名规则

```
{YYYY-MM-DD}_{topic-slug}_{platform}.md

示例：
2026-05-26_ai-and-control_wechat.md
2026-05-26_ai-and-control_x.md
```

## 发布清单

每次发布前检查：
- [ ] 对照 `../../assets/wechat-template.md` 结构检查
- [ ] 对照 `../../assets/x-thread-template.md` 格式检查
- [ ] 正文无 markdown 语法（公众号版）
- [ ] X 线程不超过 12 条
- [ ] 配图说明已生成
- [ ] 版权：所有引用素材均为公版或自写摘要
- [ ] 品牌参数一致（坐驰未来 / 片言 / slogan）
