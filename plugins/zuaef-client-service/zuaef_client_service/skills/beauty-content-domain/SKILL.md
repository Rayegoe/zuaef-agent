# Beauty Content Domain — 美妆内容域

## 用途

本 Skill 提供美妆公众号 AI 内容生产领域的域内常识与判断约束（不含真实客户语料）。

## 领域事实（来自私有 knowledge_pack）

- 内容生产方式需要持续适配平台规则与识别机制的变化（KNO 平台适配）。
- 同质化/套路化风险涉及素材来源、结构复用与批次相似性，不只是措辞层面的"去 AI 味"。
- 根因判断需要配对证据（问题稿 + 输入素材/母稿 + 平台提示）；没有配对证据只能给候选根因。
- 评价标准与参考样本应先于审核自动化（先标准后 Agent）。
- 服务层级：L1 有界真实失败稿诊断 → L2 根因与内容标准 → L3 真实样本验证方法 → L4/L5 流程与系统集成（只在方法验证后）。

## 约束

- 不承诺封号/流量恢复/检测率等平台控制之外的结果（D1 边界）。
- 大客户规模披露（账号数/日产/团队）是资格信息，不是成交信号；先轻量核验再决定高成本售前。
- 预算参考（如 L1 参考价）不等同于客户正式总预算；询价不等于预算匹配。
